# Сайт тренера: Ольга Быстрова

Одностраничный сайт на чистом HTML, CSS и JavaScript. Без сборки и зависимостей (кроме шрифтов Google Fonts: Oswald (заголовки, прописными) и Inter (текст), оба с кириллицей). Стиль: спокойный, шалфейно-зелёный с пастельными акцентами, карточки с иконками, переключатель целей, анкета.

## Структура

```
index.html   # разметка и тексты
style.css    # оформление
script.js    # меню, вкладки, анкета
images/      # фотографии
```

## Публикация на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `trainer-site`.
2. Загрузите в него все файлы вместе с папкой `images` (кнопка **Add file → Upload files**) или через git:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/trainer-site.git
   git push -u origin main
   ```
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
5. Через минуту сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/trainer-site/`.

## Что поменять под себя

- **Ссылки на Telegram и Instagram** — в `index.html` у значков в шапке и подвале (атрибут `data-social`) сейчас стоит `href="#"`. Замените на свои адреса, например `https://t.me/ВАШ_НИК` и `https://www.instagram.com/ВАШ_НИК/`. Достаточно поменять ссылки у значков в шапке: из ссылки на Telegram анкета сама берёт адрес чата. Ссылки в подвале поменяйте так же.
- **Тексты** — все в `index.html`. Цен на сайте нет: «стоимость обсуждается индивидуально».
- **Цвета и шрифты** — переменные в начале `style.css` (`:root`). Шрифты: Oswald (заголовки, прописными) и Inter (текст) с Google Fonts.
- **Первый экран** — фото `images/hero.jpg`; на фоне то же фото размыто и накрыто полупрозрачным нейтральным серым (правило `.hero::before` в `style.css`, прозрачность — число `.58`).

## Анкета и отправка в Telegram

Кнопка «Отправить» проверяет обязательные поля, собирает ответы в аккуратное сообщение, копирует его в буфер обмена и открывает чат в Telegram (если в шапке указана ссылка на Telegram). Клиенту остаётся вставить текст и отправить сообщение. Данные нигде на сайте не сохраняются.

Почему не «настоящая» отправка в одно нажатие: GitHub Pages не выполняет серверный код, а токен Telegram-бота нельзя хранить в коде страницы, любой посетитель смог бы его украсть. Если нужна полностью автоматическая отправка, подключите небольшой серверный прокси (например, Cloudflare Workers или Formspree), который хранит токен у себя и пересылает анкету в Telegram.
