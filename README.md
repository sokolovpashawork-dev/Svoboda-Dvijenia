# Сайт тренера: Ольга Быстрова

Одностраничный сайт на чистом HTML, CSS и JavaScript. Без сборки (wrangler нужен только для публикации) и без зависимостей на сайте (кроме шрифтов Google Fonts: рукописный Caveat для заголовков и Shantell Sans для текста, оба с кириллицей). Стиль: спокойный, шалфейно-зелёный с пастельными акцентами, карточки с иконками, переключатель целей, анкета.

## Структура

```
public/              # то, что публикуется на сайте
  index.html         # разметка и тексты
  style.css          # оформление
  script.js          # меню, вкладки, анкета
  images/            # фотографии
wrangler.jsonc       # настройки Cloudflare Workers (папка с сайтом: ./public)
package.json         # фиксирует версию wrangler
```

В публикацию попадает только папка `public/`: README и конфиги наружу не выходят.

## Публикация на Cloudflare Workers

Сайт разворачивается командой `npx wrangler deploy` (в Cloudflare: **Workers & Pages → squirtst → Settings → Build**, deploy command `npx wrangler deploy`). Имя воркера в `wrangler.jsonc` (`squirtst`) должно совпадать с именем воркера в Cloudflare.

Проверить локально:

```bash
npm install
npx wrangler dev
```

Публичный адрес: `https://squirtst.sokolovpashawork.workers.dev`. Чтобы отключить адрес workers.dev или превью-ссылки веток, поставьте `false` у `workers_dev` или `preview_urls` в `wrangler.jsonc`.

## Что поменять под себя

- **Ссылки на Telegram и Instagram** — в `public/index.html` у значков в шапке и подвале (атрибут `data-social`) сейчас стоит `href="#"`. Замените на свои адреса, например `https://t.me/ВАШ_НИК` и `https://www.instagram.com/ВАШ_НИК/`. Достаточно поменять ссылки у значков в шапке: из ссылки на Telegram анкета сама берёт адрес чата. Ссылки в подвале поменяйте так же.
- **Тексты** — все в `public/index.html`. Цен на сайте нет: «стоимость обсуждается индивидуально».
- **Цвета и шрифты** — переменные в начале `public/style.css` (`:root`). Шрифты: рукописный Caveat (заголовки) и Shantell Sans (текст) с Google Fonts.
- **Первый экран** — фото `public/images/hero.jpg`; на фоне то же фото размыто и накрыто полупрозрачным зелёным (правило `.hero::before` в `public/style.css`, прозрачность в числах `.74` и `.2`).

## Анкета и отправка в Telegram

Кнопка «Отправить» проверяет обязательные поля, собирает ответы в аккуратное сообщение, копирует его в буфер обмена и открывает чат в Telegram (если в шапке указана ссылка на Telegram). Клиенту остаётся вставить текст и отправить сообщение. Данные нигде на сайте не сохраняются.

Почему не «настоящая» отправка в одно нажатие: статический сайт не выполняет серверный код, а токен Telegram-бота нельзя хранить в коде страницы, любой посетитель смог бы его украсть. Если нужна полностью автоматическая отправка, подключите небольшой серверный прокси (например, Cloudflare Workers или Formspree), который хранит токен у себя и пересылает анкету в Telegram.
