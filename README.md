# Сайт тренера: Ольга Быстрова

Одностраничный сайт на чистом HTML, CSS и JavaScript. Без сборки и зависимостей (кроме шрифтов Google Fonts: Oswald для заголовков и Inter для текста). Стиль: строгий, угловатый, сливово-аубергиновая палитра по фото первого экрана; фото первого экрана также служит фоном страницы при прокрутке. Есть переключатель целей, раскрывающиеся карточки услуг, FAQ и кнопки, которые ведут в чат Telegram.

## Структура

```
index.html    # разметка и тексты
style.css     # оформление (цвета и шрифты в :root)
script.js     # меню, вкладки, связь «цель → формат»
images/       # фотографии (og.jpg: картинка для превью ссылки в мессенджерах)
robots.txt    # правила для поисковиков
sitemap.xml   # карта сайта
```

## Публикация на GitHub Pages

1. Загрузите все файлы вместе с папкой `images` в публичный репозиторий.
2. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Через минуту сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Фотографии

| Файл | Где используется |
|---|---|
| `images/hero.jpg` | первый экран и фон страницы при прокрутке |
| `images/service-2.jpg` … `service-4.jpg` | раздел «Что я предлагаю» (полосы в карточках «Другие услуги»). Оригинальные иллюстрации, сделанные для сайта (авторских прав третьих лиц нет). Можно заменить своими фото под теми же именами |

Если файла нет, блок с фото просто скрывается или остаётся заглушкой. Сжимайте фото до 200–400 КБ.

## Связь с тренером

Анкеты на сайте нет: все кнопки («Написать», «Написать в Telegram», «Выбрать этот формат», «Выбрать услугу») открывают чат `https://t.me/olga_bystrova_fox` с готовым сообщением, например: «Здравствуйте! Хочу выбрать формат «Онлайн-ведение».». Сайт сам никаких персональных данных не собирает, они остаются в переписке в Telegram.

Текст сообщения задан прямо в ссылке: параметр `?text=` в `href` каждой кнопки. Чтобы изменить текст или название услуги, поправьте его в `href` (в закодированном виде) и в `data-service`. Удобно собрать ссылку так: `https://t.me/olga_bystrova_fox?text=` + текст, закодированный функцией `encodeURIComponent`. В некоторых версиях Telegram готовый текст не подставляется, тогда просто открывается чат.

## Мобильная версия

Макет проверен на ширинах от 320 до 1440 px. Первый экран на телефоне компактный (кнопка «Написать в Telegram» видна без прокрутки), картинки ниже первого экрана грузятся лениво, зоны нажатия не меньше 40 px, вкладки и карточки услуг листаются свайпом.

## Что поменять под себя

- **Тексты** — в `index.html`.
- **Цены** — в разделе «Что я предлагаю» (классы `.offer__price` и `.feature__from` в `index.html`) стоят ориентировочные цены. Замените их на свои.
- **Названия услуг** — в карточках, во вкладках «Какая у вас цель?» (`data-pick`, `data-service`) и в тексте ссылки Telegram (`?text=`). Меняйте во всех местах сразу.
- **Цвета и шрифты** — переменные в начале `style.css` (`:root`).

## Связь «Цели → Форматы»

- В каждой вкладке цели (`#goals`) блок `.rec` подсказывает формат: основной (`.rec__item--main`, «Рекомендуем») и запасной. Ссылки имеют `data-pick="Название формата"` и `data-goal="Цель"`. Клик прокручивает к «Услугам» и подсвечивает карточку (`.is-rec`, `.offer__rec`).
- В карточках форматов строка `.offer__goals` со ссылками `data-goal-link="Название вкладки"` возвращает к нужной цели.
- Схема пути «1 → 2» над карточками: `.pathmap`.
- Чтобы изменить рекомендации, правьте блоки `.rec` в `index.html`.

## Адрес сайта и превью ссылки

В `index.html` (теги `og:url`, `og:image`, `canonical`) и в `robots.txt` / `sitemap.xml` прописан адрес `https://sokolovpashawork-dev.github.io/Svoboda-Dvijenia/`. Если сайт будет по другому адресу или появится свой домен, замените его во всех четырёх местах. Картинка превью (`images/og.jpg`, 1200×630) показывается при отправке ссылки в Telegram, VK и другие мессенджеры; после замены адреса Telegram может держать старое превью в кэше (обновить можно через бота @WebpageBot).

## Вкладки целей

Каждая цель — сливовая карточка `.gcard` с иконкой, номером 01–04, заголовком, описанием и списком. Под ней блок «Какой формат подойдёт» (`.rec`): на широком экране два формата в ряд, на телефоне друг под другом. Тексты меняйте в блоках `.gcard` и `.rec` в `index.html`.
