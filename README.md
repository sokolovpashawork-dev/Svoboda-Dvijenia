# Сайт тренера: Ольга Быстрова

Одностраничный сайт на чистом HTML, CSS и JavaScript. Без сборки и зависимостей (кроме шрифтов Google Fonts: Oswald для заголовков и Inter для текста). Стиль: строгий, угловатый, сливово-аубергиновая палитра по фото первого экрана; фото первого экрана также служит фоном страницы при прокрутке. Есть переключатель целей, раскрывающиеся карточки услуг, FAQ и анкета во всплывающем окне.

## Структура

```
index.html    # разметка и тексты
style.css     # оформление (цвета и шрифты в :root)
script.js     # меню, вкладки, анкета
images/       # фотографии
worker/       # Cloudflare Worker: отправка анкеты в Telegram
```

## Публикация на GitHub Pages

1. Загрузите все файлы вместе с папками `images` и `worker` в публичный репозиторий.
2. Откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Через минуту сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

## Фотографии

| Файл | Где используется |
|---|---|
| `images/hero.jpg` | первый экран и фон страницы при прокрутке |
| `images/goal-1.jpg` … `goal-4.jpg` | вкладки «Какая у вас цель?» (показываются целиком) |
| `images/service-1.jpg` … `service-4.jpg` | раздел «Что я предлагаю» (service-1 — фон главного блока, 2–4 — полосы в карточках). Оригинальные иллюстрации, сделанные для сайта (авторских прав третьих лиц нет). Можно заменить своими фото под теми же именами |

Если файла нет, блок с фото просто скрывается или остаётся заглушкой. Сжимайте фото до 200–400 КБ.

## Соцсети

- **Telegram** — `https://t.me/olga_bystrova_fox` (шапка и подвал; в анкете после отправки — кнопка «Открыть Telegram»).
- **Instagram, YouTube, ВКонтакте** — пока заглушки `href="#"` в шапке и подвале (`data-social="instagram|youtube|vk"`). Замените `#` на реальные адреса: клик по заглушке ничего не делает и показывает подсказку «Ссылка скоро появится».

## Анкета

Все кнопки «Заполнить анкету» / «Выбрать формат» открывают всплывающее окно с полями: услуга или формат (выпадающий список; кнопки «Выбрать этот формат» / «Выбрать услугу» в разделе «Услуги» сами подставляют выбор: «Онлайн-созвоны», «Онлайн-ведение» и др.), фамилия и имя, возраст, рост, вес и контакт для связи. Все поля обязательные.

Из ответов формируется читаемый текст («Заявка с сайта …»). Дальше два режима:

1. **С отправкой в Telegram автоматически.** GitHub Pages не выполняет серверный код, поэтому токен бота нельзя хранить на странице. Разверните Cloudflare Worker из папки `worker/` по инструкции `worker/README.md` и впишите его адрес в атрибут `data-endpoint` формы `#contact-form` в `index.html`. Заявка придёт ботом в ваш Telegram.
2. **Запасной режим** (если `data-endpoint` пуст или Worker недоступен). Текст копируется в буфер обмена, показывается в поле для ручного копирования, а кнопка «Открыть Telegram» ведёт в чат тренера.

## Мобильная версия

Макет проверен на ширинах от 320 до 1440 px. Первый экран на телефоне компактный (кнопка анкеты видна без прокрутки), картинки ниже первого экрана грузятся лениво, зоны нажатия не меньше 40 px, вкладки и карточки услуг листаются свайпом.

## Что поменять под себя

- **Тексты** — в `index.html`.
- **Цены** — в разделе «Что я предлагаю» (классы `.offer__price` и `.feature__from` в `index.html`) стоят ориентировочные цены. Замените их на свои.
- **Услуги и анкета** — каждая кнопка «Выбрать услугу / формат» имеет `data-service`; это значение подставляется в список анкеты. Если меняете название услуги, поправьте его и в `<select name="service">`.
- **Цвета и шрифты** — переменные в начале `style.css` (`:root`).
- **Услуги в анкете** — пункты `<select name="service">` в `index.html`.
