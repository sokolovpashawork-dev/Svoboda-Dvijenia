# Сайт тренера: Ольга Быстрова

Одностраничный сайт на чистом HTML, CSS и JavaScript. Без сборки и зависимостей (кроме шрифтов Google Fonts: PT Serif и Inter). Стиль: спокойный, изумрудный с пастельными акцентами, карточки с иконками, переключатель целей, анкета.

## Структура

```
index.html   # разметка и тексты
style.css    # оформление
script.js    # меню, вкладки, анкета
images/      # фотографии
```

## Публикация на GitHub Pages

1. Создайте на GitHub новый публичный репозиторий, например `trainer-site`.
2. Загрузите в него все файлы вместе с папкой `images` (кнопка **Add file → Upload files**) или через git:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/trainer-site.git
   git push -u origin main
   ```
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем **Save**.
5. Через минуту сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/trainer-site/`.

Сжимайте фото до 200–400 КБ.

## Что поменять под себя

- **Связь с клиентами** — на сайте нет ссылок на Telegram, Instagram и другие аккаунты. Все кнопки ведут к анкете (`#contact`). Чтобы добавить способ связи, впишите его в раздел «Контакты» в `index.html`.
- **Тексты** — все в `index.html`. Цен на сайте нет: «стоимость обсуждается индивидуально». Если захотите добавить цены, их нужно писать вручную в раздел «Формат работы».
- **Цвета и шрифты** — переменные в начале `style.css` (`:root`).

## Анкета

GitHub Pages не выполняет серверный код, поэтому анкета собирает текст и копирует его в буфер обмена. Данные никуда не отправляются автоматически. Чтобы получать заявки на почту или в таблицу, подключите сервис вроде [Formspree](https://formspree.io) или [Web3Forms](https://web3forms.com).
