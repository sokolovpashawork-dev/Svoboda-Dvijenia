# Отправка анкеты в Telegram

Сайт на GitHub Pages не может сам отправить сообщение в Telegram: для этого нужен токен бота, а в коде страницы его хранить нельзя, любой посетитель сможет его скопировать. Поэтому анкету принимает маленький сервер-посредник (Cloudflare Worker, бесплатно). Токен лежит у него в секретах.

Как это работает: посетитель нажимает «Отправить» → сайт шлёт текст анкеты Worker'у → Worker отправляет сообщение от имени бота в чат Ольги (@olga_bystrova_fox).

## Настройка (один раз, около 10 минут)

**1. Создайте бота.** В Telegram откройте @BotFather, отправьте `/newbot`, придумайте имя и ник (ник должен заканчиваться на `bot`). BotFather пришлёт **токен** вида `123456:ABC...`. Никому его не показывайте и не вставляйте в код сайта.

**2. Ольга запускает бота.** Ольга со своего аккаунта @olga_bystrova_fox открывает созданного бота и нажимает **Start** (бот не может писать первым). Без этого сообщения не придут.

**3. Узнайте id чата.** После шага 2 откройте в браузере ссылку  
`https://api.telegram.org/bot<ТОКЕН>/getUpdates`  
(вместо `<ТОКЕН>` подставьте токен). В ответе найдите `"chat":{"id":123456789` и скопируйте число. Это `TELEGRAM_CHAT_ID`.

**4. Создайте Worker.** На [dash.cloudflare.com](https://dash.cloudflare.com) откройте **Workers & Pages → Create → Create Worker**, назовите его `olga-form`, нажмите **Deploy**, затем **Edit code**, замените содержимое файлом `worker/worker.js` из этого репозитория и снова **Deploy**.

**5. Добавьте переменные.** В Worker'е: **Settings → Variables and Secrets → Add**:

| Имя | Тип | Значение |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Secret | токен из шага 1 |
| `TELEGRAM_CHAT_ID` | Text | число из шага 3 |
| `ALLOWED_ORIGINS` | Text | адрес сайта, например `https://sokolovpashawork-dev.github.io` (несколько через запятую, без слэша на конце) |

**6. Подключите сайт.** Скопируйте адрес Worker'а (вида `https://olga-form.ВАШ-ПОДДОМЕН.workers.dev`) и вставьте в `index.html` в атрибут формы:

```html
<form class="form modal__form" id="contact-form" data-endpoint="https://olga-form.ВАШ-ПОДДОМЕН.workers.dev" novalidate>
```

Загрузите изменённый `index.html` в репозиторий. Готово: после нажатия «Отправить» Ольге приходит сообщение «Новая анкета с сайта» с ответами в читаемом виде.

## Что если что-то не работает

- Пока `data-endpoint` пустой, кнопка «Отправить» копирует анкету и открывает чат Telegram, клиент вставляет текст сам.
- Если Worker недоступен или вернул ошибку, сайт автоматически переходит на этот же запасной вариант.
- Сообщения не приходят: проверьте, что Ольга нажала Start у бота, что `TELEGRAM_CHAT_ID` верный и что в `ALLOWED_ORIGINS` указан именно адрес сайта (с `https://`, без слэша в конце).
- Если токен случайно попал в чужие руки, перевыпустите его в @BotFather командой `/revoke` и обновите секрет в Cloudflare.

Анкета содержит сведения о здоровье. Worker ничего не сохраняет, но сообщение остаётся в переписке Telegram, поэтому доступ к аккаунту Ольги и боту стоит защитить (двухэтапная проверка).
